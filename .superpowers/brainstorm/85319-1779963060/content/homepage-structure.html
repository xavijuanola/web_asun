Homepage Flow Options

For a K-beauty shop: balance learning + discovery + buying.

1. Hero + Big Quiz CTA
2. Quiz (4 questions) → Skin type result
3. Recommended routine displayed
4. Full product grid (browse all)
5. Testimonials → Newsletter

Quiz-First Flow

Best for: Education-focused, first-time K-beauty users
Pro: Immediate guidance, personalized feel
Con: Long page if user skips quiz

1. Hero + Tagline
2. Trust strip (ingredients, cruelty-free, etc)
3. Product grid with category/skin filters
4. Floating Quiz button (bottom-right) OR section
5. Testimonials → K-beauty ritual guide → Newsletter

Grid-Primary Flow

Best for: Returning customers, confident browsers
Pro: Fast to products, classic e-comm
Con: Quiz feels secondary

1. Hero + Tagline
2. "Discover your routine" section (prominent quiz inline)
3. Product grid with smart filters
4. "K-beauty ritual" educational block
5. Reviews + Trust + Newsletter + Footer

Balanced (Recommended)

Best for: All users—education + shopping equally valued
Pro: Serves newbies AND returners
Con: Needs careful UX to not feel cluttered

The balanced approach treats learning and shopping as equals—fits Lyséa's mission.
